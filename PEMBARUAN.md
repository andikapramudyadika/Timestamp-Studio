# Memperbarui ke v1.7.1

Unggah isi paket ke repository aplikasi, termasuk location.js, location-presets.js dan map-crop.js. Pertahankan fonts/, .nojekyll dan semua berkas aplikasi lainnya. GitHub Pages tetap menggunakan root branch tanpa build atau backend tambahan.

v1.7.1 menambah lokasi perangkat, tombol sinkron WITA di atas isian waktu, beberapa preset lokasi bernama dengan opsi hapus, nilai awal Kendari/Sulawesi Tenggara, serta pemisahan edit koordinat manual dari pencarian alamat. Berkas location-presets.js wajib ikut diunggah. Preset lokasi memakai penyimpanan baru timestamp-studio-locations-v1; pengaturan lama timestamp-studio-preset-v1 tetap dapat dimuat.

Setelan lama tetap ada pada browser/domain yang sama. Tekan Muat pengaturan untuk memulihkannya. Setelan teks, font, visibilitas, posisi dan peta dipertahankan; bayangan selalu memakai default v1.6.1 dan tidak lagi dapat diubah. Gambar dan font unggahan perlu dipilih kembali sebagaimana versi sebelumnya.

Navigasi Foto, Teks, Peta, Unduh tersedia di desktop dan ponsel. Lokasi otomatis berada dalam Teks. Dua pilihan unggahan peta berada dalam Peta; pengaturan peta online dipindah ke bagian lanjutan.

Muat ulang halaman setelah Pages selesai diperbarui. Footer harus menampilkan v1.7.1. Jika masih lama, gunakan hard reload atau tab privat. Jangan menghapus penyimpanan situs bila ingin mempertahankan setelan dan preset lokasi.
